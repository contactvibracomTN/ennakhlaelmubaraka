1. Le principe : l’agent, c’est cette conversation

Il n’y a pas de site séparé ni de logiciel supplémentaire à ouvrir. L’agent est la conversation OpenCode elle-même. Le serveur meta-ads est branché à cette conversation via le protocole MCP.

Concrètement : tu continues à écrire normalement. Quand ta demande concerne Meta Ads, l’agent choisit tout seul les outils du serveur meta-ads, comme il choisirait un outil de lecture de fichier ou de recherche web.

À retenir Tu n’as pas à taper tools["meta-ads"].ads_get_ad_accounts(...). C’est l’agent qui le fait. Toi, tu écris en français.

3. Vérifier que le serveur est connecté

Dans OpenCode :

/mcps

Puis sélectionne meta-ads. Le statut attendu est :

✓ meta-ads  connected

En ligne de commande :

& "C:\Users\BY 4\AppData\Local\Programs\@opencode-aidesktop\resources\opencode-cli.exe" mcp list

Si une reconnexion est nécessaire :

& "C:\Users\BY 4\AppData\Local\Programs\@opencode-aidesktop\resources\opencode-cli.exe" mcp logout meta-ads

Puis /mcps → meta-ads → sign in.

Rappel important Le champ des URI de redirection dans l’app Meta doit rester vide. En mode développement, Meta autorise automatiquement http://localhost. N’ajoute pas http://127.0.0.1.

4. Syntaxe : comment formuler une demande

La syntaxe est du langage naturel. Il n’y a pas de commande spéciale à apprendre.

FormeExempleQuand l’utiliser
Simple Liste mes comptes publicitaires. Quand le contexte est déjà clair.
Explicite Utilise meta-ads pour lister mes comptes publicitaires. Pour forcer l’usage du serveur Meta.
Cadré Sur nakhla mubaraka, montre les campagnes actives. Quand plusieurs comptes sont accessibles.
En deux temps Propose des changements sans les appliquer. Pour analyser avant toute modification.
Avec confirmation Applique uniquement la modification que je valide. Quand tu passes aux actions d’écriture.

Bonnes pratiques de formulation

  • Précise toujours le compte : nakhla mubaraka ou act_1321318896669263.
  • Demande une seule chose principale par message.
  • Dis sans appliquer ou en lecture seule si tu veux seulement voir une proposition.
  • Si la réponse est trop technique, dis Réponds en français, simplement.
  • Si l’agent propose une action, réponds Applique seulement après avoir lu le détail.
Ne jamais coller de secret dans le chat Ne demande pas à l’agent d’afficher un token, l’App Secret ou une variable META_*. Le token OAuth est stocké par OpenCode hors du projet. Il n’a pas besoin d’apparaître ici.

5. Règles d’or pour travailler avec cet agent

Lecture d’abord

Commence par lister, lire, comparer. N’écris rien tant que tu n’as pas compris ce que l’agent a vu.

Compte explicite

Le compte accessible et activé est act_1321318896669263. Les autres comptes visibles ne sont pas la cible.

Proposition avant action

Pour une modification, demande d’abord un plan. Puis valide précisément la modification à appliquer.

Pas de déploiement implicite

Une demande Meta Ads ne déploie rien sur Vercel. Le déploiement reste différé jusqu’à nouvel ordre.

Pas de juridique automatique

La politique de confidentialité et le consentement doivent être validés avant activation CAPI et mise à jour des 8 langues.

Confirmation écrite

Toute action sensible doit être confirmée par toi dans la conversation, avec le détail de ce qui sera changé.

8. Dépannage rapide

SymptômeCause probableAction
needs authentication Session OAuth expirée ou jamais faite. /mcps → meta-ads → sign in.
Dynamic Client Registration rejected Ancienne config sans client ID. Déjà corrigé : client ID 2553279325206274 dans OpenCode.
redirect_uris are not registered URI 127.0.0.1 ajoutée dans Meta. Supprime-la. Laisse le champ vide. La config utilise localhost.
insufficient permissions Les actifs n’ont pas été sélectionnés lors du consentement. Refais le sign in et sélectionne le compte publicitaire et la Page.
Aucun outil n’apparaît Le client n’a pas rechargé la liste des outils. Redémarre OpenCode, puis /mcps → reconnecte.
is_ads_mcp_enabled: false Ce compte n’est pas encore activé par Meta. Utilise act_1321318896669263.
